# 🎮 Angular Arcade

A modern arcade game collection built with **Angular 22**, **TypeScript**, **SCSS**, and **Angular Material**. This project showcases multiple classic browser games with a clean UI and responsive design.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/Chiki1601/angular-arcade-games.git
```

Navigate into the project

```bash
cd angular-arcade-games
```

Install dependencies

```bash
npm install
```

Run the application

```bash
ng serve
```

Open your browser

```
http://localhost:4200
```

---

# 🏗 Build

```bash
ng build
```

Production build

```bash
ng build --configuration production
```

---

# 🧪 Testing

Run unit tests

```bash
ng test
```
